## Introduction to redSHOP

<h4 id="whatIs">What is redSHOP?</h4>

redSHOP is an e-commerce extension for Joomla. It provides catalogue, customer, order and checkout workflows; available capabilities depend on configuration and installed extensions.

<h4 id="license">License</h4>

The current Core source declares `GPL-2.0-or-later` in its Composer metadata; check the license files and package metadata for the exact release and any separately distributed extensions. Documentation and third-party assets may have different licenses.

<h4 id="overview">Features and requirements</h4>

Start with [requirements](chapters/getting-started-general/redshop-minimum-requirements.md), [installation](chapters/getting-started-general/installing-redshop.md), [configuration](chapters/global-configuration/start-here.md) and the [product guide](chapters/product-management/products-redshop.md). Verify the exact Joomla, PHP and extension versions and test on an isolated shop.

<h4 id="support">Support</h4>

Support availability and scope depend on the provider and current agreement. Consult the current terms and contact channel for your package; historical subscription promises are not a current support contract.

<h4 id="notCover">Support scope</h4>

Confirm responsibility for upgrades, customizations, third-party integrations and incident response before deployment. Keep backups and an independently tested recovery plan.

<h4 id="extensions">Extensions</h4>

Optional plugins and modules can have separate releases, requirements and licenses. Check their installation, configuration and compatibility independently.

<h4 id="templates">Templates</h4>

Templates control presentation and available tags; see [Templates](chapters/customization/template.md). Test custom templates after updates.

<h4 id="integrations">Integrations</h4>

Payment, shipping and accounting integrations depend on installed plugins and providers. See [Plugins](chapters/plugin-redshop/overview-plugin.md) and verify each provider with isolated test credentials and mock transactions.
