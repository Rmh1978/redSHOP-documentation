## Import/Export

Import and export use installed and enabled redSHOP plugins; available data types and options vary. Back up and test with disposable data on an isolated copy, and protect any customer or order data.

- [Data Import](chapters/import-export/data-import.md): prepare CSV files, inspect row results and verify changed records before retrying.
- [Data Export](chapters/import-export/data-export.md): review filters, verify the downloaded file and store it securely. An export is not a full site backup.
