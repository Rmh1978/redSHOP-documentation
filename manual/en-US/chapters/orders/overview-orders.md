## Orders

Use the order tools to review and manage customer transactions:

- [Order list](chapters/orders/order-list.md) covers finding and updating orders.
- [Add order](chapters/orders/add-order.md) describes administrator-created orders.
- [Order statuses](chapters/orders/order-status-list.md) explains status records and transitions.
- [Quotations](chapters/orders/quotations.md) covers quotes and their workflow.
- [Product order search](chapters/orders/product-order-search.md) helps locate orders by product.

Order and payment statuses are separate. Verify payment with the configured provider and test changes with disposable orders before using them in a live shop.

## Review or create an order

1. Find the order using the list's search and filters, then check its customer, items, totals and separate order and payment statuses.
2. Before changing status, review notification settings and any stock, accounting or plugin effects. Confirm payment independently with the provider.
3. For an administrator-created order, apply customer information, add products and review shipping, tax, discounts and totals before saving.
4. If using quotations, review the quotation separately and verify any resulting order and payment after conversion.

Treat exports and order details as sensitive. Review retention obligations and take a backup before deleting orders; verify exports with non-sensitive test data before relying on them.
