## Module for redSHOP

These optional site modules provide navigation, product displays, cart tools and integrations. Availability and compatibility depend on the exact package and installed Joomla/redSHOP versions. Install and test each module on an isolated shop first; menu visibility or a product listing is not a substitute for access checks.

## Configure and verify a module

1. Install the appropriate package and create a module instance in Joomla administration. Set its position, menu assignments and publication state.
2. Review the module's own options and the active template. For product and cart displays, check that selected products, prices, taxes and links match the shop's settings.
3. Test separate customer sessions and access levels before changing caching or relying on group-specific display. For currency modules, independently verify conversion and payment currency.
4. Preview on the intended pages with disposable data and review mobile and keyboard behavior before publishing it on a live shop.
