## Product and catalog media

The [media management guide](chapters/media/working-medias.md) is the current reference for media records, upload precautions, associations and deletion. Media controls and output vary by section and active template.

<h2 id="overview-1">Media list</h2>

The list can filter by media type and section and displays the associated item, alternative text, publication state and ID. Select column headings to sort. To clear filters, choose **Select** in each filter; the current Reset button may not clear them.

<h2 id="overview-2">Media details</h2>

Choose an image, video, document or YouTube type, then review the section, associated item, alternative text and publication state before saving. Published defaults to Yes. The product dialog also offers download; manufacturer and catalog contexts use image and document respectively. Use non-sensitive sample files for testing; media storage is not a substitute for protected paid downloads.

<h2 id="overview-3">Working with media</h2>
<h4 id="create-item">Create a media record</h4>

Open Media, select New, enter the available details and save. Reopen the record and verify its association and output.

<h4 id="create-product">Product media</h4>

Save a product before adding its additional images through the product media dialog. Preview the actual product template.

<h4 id="create-category">Category media</h4>

Use the category editor's image controls or associate an appropriate media record with a category. Verify the category page and active template.

<h4 id="upload-product">Upload for a product</h4>

Use the saved product's additional-media dialog. Upload trusted files only and verify server-side limits and access controls independently.

<h4 id="add-product">Add media to a product</h4>

Check the product context, media type and published state in the dialog, then save and preview the gallery.

<h4 id="create-manufacturers">Manufacturer media</h4>

Use the manufacturer media association and verify storefront output. Avoid the `medium.remove` manufacturer cleanup path until the separately identified deletion issue is reviewed.

<h4 id="use-media">Storefront display</h4>

Verify images, thumbnails and alternative text in the active template. Before removing shared files or records, back up both files and database and review the deletion precautions in the [media management guide](chapters/media/working-medias.md).
