# Integration notes

- If the destination repository already contains `.github/copilot-instructions.md` or `AGENTS.md`, merge instructions manually; do not overwrite existing repo guidance.
- GitHub Copilot Chat in VS Code should be used in **Agent** mode when authorized to modify local files, or **Ask** mode for initial review.
- Workspace should contain both repositories; use actual repository files, not assumed source excerpts.
- The stage archives are reference material and may include repeated/older issue trackers. The top-level master is canonical.
- Keep the historical changelog as an archive; current release data must be read from the actual `develop` manifest, changelog and release system, which may have advanced since the audits.
- GitHub branches and published documentation are unchanged by this package.
